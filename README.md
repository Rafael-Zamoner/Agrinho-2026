# Agro Drone - Uso de Drones na Agricultura

## Sobre o Projeto

O Agro Drone é um site educativo desenvolvido para apresentar a importância dos drones na agricultura moderna. O projeto demonstra como essa tecnologia auxilia produtores rurais no monitoramento de plantações, redução de custos, aumento da produtividade e preservação ambiental.

Além do conteúdo informativo, o projeto inclui um mini jogo interativo, onde o jogador controla um drone agrícola e realiza missões inspiradas em atividades reais do agronegócio.

---

## Objetivos

* Apresentar o uso dos drones na agricultura.
* Demonstrar os benefícios da agricultura de precisão.
* Explicar os impactos econômicos e ambientais dessa tecnologia.
* Proporcionar uma experiência prática por meio de um mini jogo educativo.

### Mini Jogo

O jogador controla um drone agrícola utilizando o teclado.

#### Controles

* W ou seta para cima: mover para cima
* S ou seta para baixo: mover para baixo
* A ou seta para esquerda: mover para esquerda
* D ou seta para direita: mover para direita

#### Missões

1. Abastecer o drone no depósito de produto.
2. Pulverizar toda a área da plantação.
3. Coletar frutas espalhadas pelo campo.
4. Entregar a carga ao caminhão.
5. Concluir a missão agrícola.
